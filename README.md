# Jeu des différences — Projet intégrateur LOG3900

Application web et mobile multijoueur inspirée du jeu "Trouver les différences".
Développée en équipe de 6 dans le cadre du cours LOG3900 à Polytechnique Montréal.

## Stack technique
- Frontend web : Angular / TypeScript
- Application mobile : Flutter / Dart
- Backend : NestJS
- Base de données : MongoDB

## Fonctionnalités principales
- Mode solo et multijoueur en temps réel
- Gestion et création de niveaux personnalisés
- Système d'amis et de clavardage intégré
- Création de lobbies pour jouer avec des amis ou des inconnus
- Mode spectateur : les autres joueurs peuvent observer vos parties en direct
